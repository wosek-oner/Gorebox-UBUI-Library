# Gorebox-UBUI-Library
Unity Based User Interface 1.0
Made by Wosek
UBUI is an open library, absolutely free to use.


The documentation is placed in /documentation.

# Basics:

Load the UBUI using File.DoFile(path)

To load the ubuistyles.lua, you must use UBUI.LoadStyles(path)

 

Call UBUI.UIUpdate in Update()

 

This library works only on 16.4.

It might have bugs or other issues, if so, please contact me.
